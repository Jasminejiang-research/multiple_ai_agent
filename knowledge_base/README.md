# Knowledge Base

This directory contains curated, reviewable material used by the proposal
generation system. Keep source provenance and usage rights with every document
added in later sprints.

- `proposal_templates/`: reusable proposal structures and section templates.
- `business_frameworks/`: business analysis frameworks and guidance, such as
  SWOT, TAM/SAM/SOM, and unit economics.
- `example_proposals/`: example proposals used as writing and structure
  references, not as authoritative factual sources.
- `industry_research/`: industry-specific research material whose origin,
  publication date, and other source metadata must remain traceable.
